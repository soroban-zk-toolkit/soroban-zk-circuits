Circom zero-knowledge circuits for identity, membership, nullifier, and range proof verification on Stellar.

> **Warning** These circuits are unaudited research-grade implementations. Do not use in production without an independent security review.

---

## Overview

`soroban-zk-circuits` provides reusable Groth16 ZK circuits for the Soroban ZK Toolkit ecosystem. Proofs generated by these circuits are verified on-chain by the companion [`soroban-zk-verifier`](https://github.com/soroban-zk-toolkit/soroban-zk-verifier) Soroban smart contract.

### Use Cases

- **Private identity** — prove you own a credential without revealing it
- **Anonymous membership** — prove your address is in an allowlist without revealing which one
- **Confidential amounts** — prove a balance or payment is within a range without revealing the value
- **Double-spend prevention** — nullifier scheme prevents reuse of secrets

---

## Circuits

| Circuit | File | Description | Constraints |
|---------|------|-------------|-------------|
| Identity | `identity.circom` | Commitment to secret identity + nullifier hash | ~2 000 |
| Membership | `membership.circom` | Merkle-tree membership proof (depth-20) | ~8 000 |
| Nullifier | `nullifier.circom` | Unique nullifier derivation | ~1 500 |
| Range Proof | `range_proof.circom` | Prove value in [low, high) | ~4 000 |

## Quick Start

### Prerequisites

```bash
# Rust + circom
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
git clone https://github.com/iden3/circom && cd circom
cargo build --release && cp target/release/circom /usr/local/bin/

# snarkjs
npm install -g snarkjs
```

### Trusted Setup

```bash
./scripts/setup.sh identity
./scripts/setup.sh membership
./scripts/setup.sh nullifier
./scripts/setup.sh range_proof
```

### Generate a Proof

```bash
# Edit inputs/identity_input.json with your values
./scripts/generate-proof.sh identity inputs/identity_input.json
```

### Verify Locally

```bash
./scripts/verify-proof.sh identity
```
